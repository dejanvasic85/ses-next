## Diagnosis log — the August click collapse

Work done 2026-09-10 against issue #695. This section is the record of the month's
SEO work for invoicing, because the diagnosis ran through Search Console and curl
and left no commit trail of its own.

### What we set out to test

August's scorecard found clicks and phone leads falling while rankings held or
improved. The leading hypothesis was the design-system and nav rebuild (PR #648/#650,
30 July) and the services hub redesign (PR #671/#672, 8 August), both of which shipped
inside the measurement window. Issue #695 set two checks before any new content work:
are Google's snippets stale, and does the click-to-call event still fire.

### Check 1 — stale SERP snippets: ruled out

URL Inspection on `/locations/electrician-seddon` came back healthy. Last crawl
3 September, well after both rebuilds. Page fetch successful, page indexed, canonical
correct. A `site:sesmelbourne.com.au` search showed current, well-formed snippets
across the home, services, blog, FAQ and terms pages. Snippets are not the problem.

### Check 2 — the rendered screenshot: this is the real finding

The Inspection Tool's rendered screenshot showed the page completely unstyled: nav as
a bullet list, blue underlined link text, an unsized phone icon filling the viewport.

We traced the cause. `robots.txt` carries `Disallow: /_next/`, which blocks every
stylesheet and script the site serves. Fetching the page as Googlebot smartphone
returns HTTP 200 and both stylesheets serve fine on their own (1KB and 148KB, correct
content type), so the assets are healthy. Googlebot is simply not allowed to request
them.

Google has warned since 2015 that blocking CSS and JS harms rankings, because it cannot
assess mobile-friendliness or layout on a page it cannot render. The timing fits the
August collapse: a design-system rebuild increases how much the page depends on CSS,
so the cost of hiding that CSS from Google rises at the same moment.

This is a cause worth acting on, not a confirmed explanation of the full click drop.
October's numbers are the test.

### Check 3 — click-to-call markup: broken

The phone link renders as `href="tel:0415 338 040"` with raw spaces, where it should be
`tel:+61415338040`. This is a plausible cause of GA4 `first_time_phone_call` falling
from 23 in July to 2 in August.

### Also found

- The phone number in the Seddon page's meta description, (03) 4050 7937, does not match
  the 0415 338 040 in the page body. Karl is updating the content.
- The FAQ page's meta description double-escapes an ampersand. It reaches the live SERP
  as `solar &amp; more`.

### Actions

- [ ] Remove `Disallow: /_next/` from robots.txt, or narrow it to `/_next/data/`
- [ ] Fix the `tel:` href to E.164 format
- [ ] Fix the `&amp;` double-escape in the FAQ meta description
- [ ] Re-run URL Inspection after deploy and confirm the render comes back styled
- [ ] Held off on new SEO content this month, per issue #695
